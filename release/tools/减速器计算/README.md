# 减速器计算工具 V1.0

机械工程用减速器设计与选型计算工具，基于 Python tkinter 的独立桌面应用。

## 功能模块

### Tab 1 - 传动计算
- 输入功率、转速、传动比、传动类型、载荷类型
- 计算输出转速、输入/输出扭矩、效率、功率损耗
- 支持: 单级圆柱齿轮、两级圆柱齿轮、三级圆柱齿轮、行星齿轮、蜗轮蜗杆

### Tab 2 - 齿轮参数
- 齿数、模数、压力角、齿宽系数输入
- 计算分度圆直径、中心距、齿顶圆/齿根圆直径、基圆直径、齿距、齿宽、重合度
- 内置 GB/T 1357 标准模数快速选择

### Tab 3 - 强度校核
- 齿面接触强度 (Hertz公式) 和齿根弯曲强度校核
- 自动根据齿数估算齿形系数和应力修正系数
- 内置12种常用齿轮材料数据 (含接触/弯曲疲劳极限)
- 输出安全系数和校核结论

### Tab 4 - 减速器选型
- 根据输入功率、转速和传动比自动推荐减速器型号
- 覆盖: ZDY (单级)、ZLY (两级)、ZSY (三级)、NGW (行星)、CWU (蜗轮蜗杆)
- 表格展示额定参数、效率、质量和功率裕度

## 计算公式

| 项目 | 公式 |
|------|------|
| 传动比 | i = n₁ / n₂ = z₂ / z₁ |
| 输出扭矩 | T₂ = T₁ × i × η |
| 功率 | P = T × n / 9550 (kW) |
| 分度圆直径 | d = m × z |
| 中心距 | a = m × (z₁ + z₂) / 2 |
| 齿面接触应力 | σ_H = Z_H × Z_E × √(2KT₁/(bd₁²)) × √((u+1)/u) |
| 齿根弯曲应力 | σ_F = (2KT₁)/(bmd₁) × Y_F × Y_S |

## 数据库

SQLite 数据库 (`reducer.db`) 包含:
- GB/T 1357 标准模数 (第一/第二系列)
- 12种齿轮材料 (含热处理、硬度、疲劳极限)
- 5类标准减速器系列参数 (ZDY/ZLY/ZSY/NGW/CWU)
- 20个标准传动比

## 运行

```bash
cd 减速器计算
python main.py
```

首次运行会自动创建 SQLite 数据库。

## 依赖

- Python 3.6+
- tkinter (Python 标准库)
- sqlite3 (Python 标准库)
