# 联轴器选型工具 V1.0

基于 Python tkinter 的联轴器选型计算工具，支持多种标准联轴器系列的自动选型与校核。

## 功能特性

- **两种输入方式**: 按功率+转速计算，或直接输入工作扭矩
- **四项校核**: 扭矩、转速、轴孔直径、补偿量
- **四大系列**:
  - 弹性柱销联轴器 (HL) — GB/T 5014
  - 弹性套柱销联轴器 (LT) — GB/T 4323
  - 梅花形弹性联轴器 (ML) — GB/T 5272
  - 膜片联轴器 (JM) — GB/T 12922
- **结果导出**: 支持将选型结果导出为文本文件

## 计算原理

### 计算扭矩

```
Tca = KA × K × Kw × T
```

- **T**: 工作扭矩 (N·m)
  - 按功率计算: T = 9550 × P / n
- **KA**: 工况系数 (载荷性质)
  - 平稳载荷: 1.0~1.5
  - 轻度冲击: 1.5~2.0
  - 中等冲击: 2.0~2.5
  - 重度冲击: 2.5~3.0
- **K**: 温度系数
  - ≤100°C: 1.0, ≤150°C: 1.1, ≤200°C: 1.2, ≤250°C: 1.3
- **Kw**: 启动系数
  - 启动不频繁: 1.0, 频繁启动: 1.3~1.5

### 选型条件

1. Tca ≤ Tn (公称扭矩)
2. n ≤ n_max (许用转速)
3. d1, d2 在轴孔直径范围内
4. 补偿量满足需求
