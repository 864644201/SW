# 轴承计算工具 V1.0

基于 ISO 281 / GB/T 6391 标准的轴承寿命计算与选型工具。

## 功能

- **寿命计算**: 输入轴承型号和工况参数，计算基本额定寿命 L10、修正额定寿命 Lna（折算为小时和年）
- **自动选型**: 给定载荷、转速和要求寿命，从数据库中自动推荐满足条件的轴承
- **静载荷校核**: 自动校核当量静载荷是否在安全范围内

## 使用方法

### 运行

```bash
cd 轴承计算
python main.py
```

首次运行会自动创建 SQLite 数据库 `bearings.db`（也可手动运行 `python init_db.py` 重建）。

### 操作步骤

1. 选择轴承类型（深沟球轴承 / 角接触球轴承 / 圆锥滚子轴承）
2. 输入径向载荷 Fr、轴向载荷 Fa（kN）、转速 n（RPM）
3. 输入要求寿命和可靠度
4. 点击「计算寿命」查看指定型号的寿命，或点击「自动选型」获取推荐列表

## 数据库

内置 60+ 个标准轴承型号，包括：

| 类型 | 系列 | 数量 |
|------|------|------|
| 深沟球轴承 | 60xx, 62xx, 63xx | 29 |
| 角接触球轴承 | 70xxC, 72xxC | 20 |
| 圆锥滚子轴承 | 302xx | 12 |

## 文件说明

| 文件 | 说明 |
|------|------|
| `main.py` | 主界面，tkinter GUI |
| `bearing_calc.py` | 计算引擎（寿命、当量载荷、选型） |
| `bearing_db.py` | 数据库查询接口 |
| `init_db.py` | 数据库初始化（标准轴承数据） |
