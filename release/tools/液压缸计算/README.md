# 液压缸计算工具 V1.0

基于 Python tkinter 的液压缸设计计算工具。

## 文件结构

```
液压缸计算/
├── main.py           # 入口, tkinter GUI
├── hydraulic_calc.py # 计算引擎
├── hydraulic_db.py   # 标准数据库查询
├── init_db.py        # 数据库初始化
└── hydraulic.db      # SQLite 数据库(自动创建)
```

## 功能

### Tab 1 - 参数计算
输入推力、压力、速比、流量等参数，综合计算：
- 缸筒内径 D (自动圆整至 GB/T 2348 标准值)
- 活塞杆直径 d (按速比计算并标准化)
- 推力 F1 / 拉力 F2
- 前进速度 v1 / 返回速度 v2
- 液压功率
- 缸筒壁厚 (Lamé 公式 + 简化公式)
- 稳定性校核 (欧拉公式)

### Tab 2 - 缸筒设计
独立的壁厚计算模块，可自定义材料许用应力和安全系数。

### Tab 3 - 选型参考
- HSG01 系列工程液压缸选型 (按推力/压力筛选)
- 密封件推荐 (按缸径/杆径匹配)

## 运行

```bash
cd 液压缸计算
python main.py
```

首次运行自动创建 `hydraulic.db` 数据库。

## 依赖

- Python 3.6+
- tkinter (标准库)
- sqlite3 (标准库)

无需额外安装第三方库。

## 标准依据

- GB/T 2348 液压缸缸筒内径及活塞杆直径系列
- HSG01 系列工程液压缸技术参数
- 欧拉压杆稳定公式
