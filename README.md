# 麦豆宝工具集

SolidWorks 机械设计工具集，包含齿轮设计、轴计算、弹簧设计、公差查询、型材选型仿真等 28 个专业模块。

## 快速使用

1. 下载 `release` 目录
2. 双击 `mdb.exe` 启动

### 表格工具大全

用于承载表格类工具的新一级菜单，当前已预留入口，后续可继续接入 Excel、明细表整理、数据批处理等功能。

### 大国工匠

支持添加外部 exe 工具，三种方式：

1. **自动扫描**：将 exe 文件夹放入 `tools` 目录，自动识别
2. **手动添加**：点击"添加程序"按钮选择 exe
3. **配置文件**：编辑 `custom_tools.txt`，格式为 `名称|路径`

右键菜单支持重命名和删除。

## 编译环境

- Visual Studio 2022 或 .NET SDK 8.0
- .NET Framework 4.8

```bash
# 编译
dotnet build MaidouBao.sln -c Release

# 输出位置
src\MaidouBao.Launcher\bin\Release\net48\
```
