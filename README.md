# 麦豆宝工具集

SolidWorks 机械设计工具集，包含齿轮设计、轴计算、弹簧设计、公差查询、型材选型仿真等 16 个自研模块，以及经典机械设计手册、表格工具、书籍资料和外部工具集成。

## 快速使用

1. 下载 `release` 目录
2. 双击 `mdb.exe` 启动

### 表格工具大全

自动扫描 `tables` 目录下的 Excel 文件（xlsx/xls），点击直接打开。

- 将 Excel 文件放入 `tables` 目录即可自动显示
- 支持子目录扫描
- 点击"刷新"按钮可实时更新列表
- 右键可打开文件所在目录

### 书籍资料

自动扫描 `books` 目录下的文档文件，支持 PDF/CHM/EPUB/TXT/DOC 等格式。

- 内置阅读器，支持 PDF 书签和目录导航
- 支持标签分类，右键可设置书籍分类
- 分类筛选栏支持按标签快速过滤
- 将书籍文件放入 `books` 文件夹可自动显示

### 大国工匠

支持添加外部 exe 工具，三种方式：

1. **自动扫描**：将 exe 文件夹放入 `tools` 目录，自动识别
2. **手动添加**：点击"添加程序"按钮选择 exe
3. **配置文件**：编辑 `custom_tools.txt`，格式为 `名称|路径`

右键菜单支持重命名和删除。

## 目录结构

```
release/
├── mdb.exe              主程序
├── custom_tools.txt     大国工匠配置（自动维护，无需手动编辑）
├── books_categories.txt 书籍分类数据
├── tools_sort.txt       模块排序数据
├── data/                自研模块（16个，含 Plugin.xml）
├── 2008/                机械设计手册工具（17个经典工具）
├── tools/               大国工匠外部工具（自动扫描）
├── tables/              表格工具目录（放入 xlsx/xls 自动显示）
├── books/               书籍资料目录（放入文档自动显示）
└── *.dll                运行时依赖
```

## 编译环境

- Visual Studio 2022 或 .NET SDK 8.0
- .NET Framework 4.8

```bash
# 编译
dotnet build MaidouBao.sln -c Release

# 输出位置
src\MaidouBao.Launcher\bin\Release\net48\
```

## 项目结构
